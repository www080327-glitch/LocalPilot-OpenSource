# Linux Desktop：构建、安装与验收范围

日期：2026-11-16。源码候选 Desktop 5.0.1-rc.8、Core 5.0.0b23、Suite 0.2.0b28、Companion 0.5.7b5、Channels 0.1.0a3。

## 当前支持方式

Linux 原生 Tauri 桌面使用 GTK3 / WebKitGTK 4.1，保留现有主界面、认证 Core 连接、提交账本、SSE、Session、模型库和四档权限。AppKit、Liquid Glass、macOS 签名/APP 安装事务均按目标系统隔离。Linux 桌宠使用普通 WebView 指针事件，不声称拥有 macOS 的透明像素点击穿透。模型路由使用已有本机/云端 OpenAI 兼容端点；Linux aarch64 也不会误进入 Apple Silicon MLX 分支。

构建基线是 **Debian 13 x86_64，系统 CPython 3.13**。DEB 携带四组件 wheel、35 个运行依赖、pip 和隔离模块环境；Python 标准库/解释器由发行版提供，DEB 显式依赖 `python3.13`。资源可在同一发行版环境搬移，未复制开发者 `/usr`、全局 site-packages、用户配置、模型、凭据或数据库。默认 Node 归档为 Suite 固定哈希核验的官方 Linux Node 22.23.4。

这不是任意 Linux 通用包：WebKitGTK、glibc、系统 Python 小版本和架构必须匹配。Debian 12 / Ubuntu / ARM Linux 需要在目标基线上原生构建并重新生成其依赖锁，再完成实机验收。本轮没有产出 AppImage、RPM 或 Linux arm64 合格包。[Tauri 官方 Linux 前置依赖](https://v2.tauri.app/start/prerequisites/)与 [Debian 打包说明](https://v2.tauri.app/distribute/debian/)同样要求关注构建系统依赖。

## 快速安装与独立身份

只有实际生成并通过校验的 DEB 才可安装；本轮未发布 Release，示例文件名不是下载链接。在构建输出目录执行：

```sh
sha256sum -c SHA256SUMS
sudo apt install ./LocalPilot-5.0.1-rc.8-linux-x86_64.deb
localpilot-desktop
```

独立测试包的文件名为 `LocalPilot-Test-5.0.1-rc.8-linux-x86_64.deb`，运行 `localpilot-desktop-test`；DEB 名为 `local-pilot-test`，Tauri 身份为 `io.localpilot.desktop.test`。正式包为 `local-pilot` / `io.localpilot.desktop`。两个身份的程序、资源和默认应用数据目录分开。

首次打开完成组件准备，选择现有 HTTP 模型端点并读取模型列表，保存实际模型 ID 和上下文。安装不下载权重，也不自动调用模型。只有发送任务后才构成真实模型/Agent 验收。

桌面升级由 `apt install ./新包.deb` 管理；需要降级时由用户选择已留存且哈希匹配的旧 DEB 再安装。组件升级仍使用设置中的现有独立事务。Linux GUI 不提供 macOS APP 事务入口；本轮的 DEB 提取验证不等于安装/降级实测。

## 从源码构建 Debian 13 x86_64

准备官方 Rust stable、Node.js 22 和以下发行版开发包。以下命令会安装系统依赖，应在你选择的构建机执行；本轮受限验证环境采用用户目录 sysroot，没有改动系统安装。

```sh
sudo apt install build-essential pkg-config libwebkit2gtk-4.1-dev \
  libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libssl-dev \
  libxdo-dev patchelf dpkg-dev python3-dev python3-venv \
  xdg-utils zenity bubblewrap
```

在仓库根目录建立新的构建槽，不覆盖已有 wheel 或资源：

```sh
export LP_LINUX_BUILD="$PWD/.build-linux/$(date +%Y%m%d-%H%M%S)"
mkdir -p "$LP_LINUX_BUILD/wheels" "$LP_LINUX_BUILD/dependencies"
/usr/bin/python3 -m venv "$LP_LINUX_BUILD/build-env"
"$LP_LINUX_BUILD/build-env/bin/python" -m pip install 'setuptools>=77' wheel build
for component in . companion suite; do
  "$LP_LINUX_BUILD/build-env/bin/python" -m build --wheel --no-isolation \
    --outdir "$LP_LINUX_BUILD/wheels" "$component"
done
"$LP_LINUX_BUILD/build-env/bin/python" scripts/build_channels_wheel.py \
  --no-isolation --out "$LP_LINUX_BUILD/wheels"
```

该组件构建使用仓库既有 setuptools / build 流程。35 个依赖的版本沿用 macOS 基线；Linux 使用自己平台的官方 wheel 哈希，绝不复制 macOS wheel。仓库提供 Debian 13 x86_64 / CPython 3.13 的独立锁，连同启动所需的 pip 共 36 项。生成 pip 哈希要求并下载：

```sh
"$LP_LINUX_BUILD/build-env/bin/python" - <<'PY'
import json, os
from pathlib import Path
lock = json.loads(Path('desktop/runtime-dependencies-linux-x86_64-py313.json').read_text())
out = Path(os.environ['LP_LINUX_BUILD']) / 'dependencies.txt'
out.write_text(''.join(f"{name}=={item['version']} --hash=sha256:{item['sha256']}\n" for name, item in lock['packages'].items()))
PY
"$LP_LINUX_BUILD/build-env/bin/python" -m pip download \
  --index-url https://pypi.org/simple --no-deps --only-binary=:all: --require-hashes \
  --dest "$LP_LINUX_BUILD/dependencies" -r "$LP_LINUX_BUILD/dependencies.txt"
curl -fL https://nodejs.org/dist/v22.23.4/node-v22.23.4-linux-x64.tar.gz \
  -o "$LP_LINUX_BUILD/node-v22.23.4-linux-x64.tar.gz"
```

确保 `desktop/src-tauri/bundled-backends` 尚不存在；若已有自己的旧候选，先保留到另一个明确命名的槽。资源生成器拒绝覆盖现有目录。

```sh
"$LP_LINUX_BUILD/build-env/bin/python" desktop/scripts/linux_backends.py prepare \
  --python /usr/bin/python3 \
  --wheels "$LP_LINUX_BUILD/wheels" \
  --dependencies "$LP_LINUX_BUILD/dependencies" \
  --dependency-lock desktop/runtime-dependencies-linux-x86_64-py313.json \
  --channel-runtime "$LP_LINUX_BUILD/node-v22.23.4-linux-x64.tar.gz"
cd desktop
npm ci
LP_GUI_USE_INSTALLED_DEPS=1 npm run release:linux
```

隔离原生检查时，最后一条替换为：

```sh
LP_GUI_USE_INSTALLED_DEPS=1 LP_GUI_TEST_CONFIG=src-tauri/tauri.test.conf.json npm run release:linux
```

入口复用既有构建锁，固定一个 Cargo worker。输出位于新的 `release/linux-v5.0.1-rc.8/<运行编号>/` 或 `release/linux-test-v5.0.1-rc.8/<运行编号>/`。目录保存实际 DEB、`SHA256SUMS`、最终配置和 `RESULTS.json`。Tauri 默认解引用资源符号链接；打包脚本会在自有暂存目录把三个 Python 入口恢复为系统解释器链接，重新生成 DEB 文件清单与安装大小，再生成交付包，原始 Tauri 包与交付包的哈希均记录。

脚本检查包身份、版本、架构、Python 小版本依赖，提取交付 DEB 到带空格的新路径，执行原生 `--bundle-self-check`、四组件及二进制依赖的真实导入、`pip check`、Suite 版本命令和所附 Node 的版本命令。全部完成才写成功记录；`installed:false` 明确说明未安装。失败输出保留在自己的运行槽，没有 `RESULTS.json` / `SHA256SUMS` 的包不作为通过的交付。

其他发行版/Python 小版本先用其系统 Python 下载与 `runtime-dependencies.json` 同版本的原生 wheel，再以 `linux_backends.py lock --python /usr/bin/python3 --dependencies <目录> --dependency-lock <新的锁>` 查询官方 PyPI 元数据核对文件名和 SHA256。锁生成不代表该平台验收通过。受控 Linux 构建仍使用本地固定 wheel，安装时不在线解析依赖。

## 可选观察与会议

Linux Companion 可使用系统 AT-SPI 做授权应用的只读界面观察。安装 `python3-gi gir1.2-atspi-2.0`，在实际桌面会话启用辅助功能并显式授权应用范围。D-Bus、AT-SPI 和应用自身的可访问性决定可见信息；Wayland 下不可读取的内容应报告缺失，不推断成已观察。该通路不提供 Core 的 macOS Computer Use 操作能力。

会议使用显式选定的 PulseAudio / PipeWire Pulse 来源和本地 whisper.cpp，需 `ffmpeg pulseaudio-utils`、已校验的本地模型及 `whisper-cli`。在 Companion 配置 JSON 中填写 `meeting_microphone_source`、`meeting_system_source`、`meeting_whisper_command`、`meeting_whisper_model` 和 `meeting_whisper_model_sha256`；命令与模型使用绝对路径。`meeting-devices` 只列设备，开始采集仍由会议开始操作显式触发。音频通过内存交给本地转写器，不保存原始音轨。GUI 会显示 Linux 工具/来源/模型是否就绪，不提示用户去 macOS TCC 设置。

详细配置、只读范围、系统电源和 systemd 用户服务见 [Companion Linux 指南](../../../docs/development/LINUX_COMPANION_20261116.md)及 [Companion README](../../../companion/README.md)。

## 验证与待完成范围

本轮实际使用 Rust 1.100.0，GTK3 3.24.49 / WebKitGTK 2.54.0，真实组件及依赖资源进行 Linux 编译。Rust 默认测试已通过 45 项，3 项按定义忽略；其中真实 Core HTTP 恢复/身份用例又显式执行并通过，模型为脚本夹具。它验证关闭 Session 拒绝、下次新提交、丢失 POST 回应后同键恢复不重复建任务、两个身份隔离，不是模型能力测评。发布编译保留了两个既有未使用几何/点击辅助函数警告；其旧测试不能证明当前原生 GUI 的坐标或点击行为。

前置编译失败和既有扫描测试对 `/Applications` 的假定均保留；扫描测试现使用自己创建的外部目录和标记文件，真实验证不会跟随符号链接进入目录。PR #13 的 Intel UI 夹具 `.slice()` 修复保留，未将合成桥结果表述为原生产品验收。

前端新增 Linux 首次设置、Linux 包升级提示和独立测试集选择 3 个 UI 场景，共 41 个 Playwright 用例。当前容器 Chromium 启动被 AF_UNIX `EPERM` 阻止，且官方浏览器下载返回不完整归档；这些 UI 用例没有报为通过。桌面 GUI、托盘、文件对话框、Wayland 桌宠拖动和原生辅助功能仍需有正常桌面会话的 Linux 主机执行。

当前候选的实际 DEB 校验结果以本轮打包 `RESULTS.json` 与总验收记录为准。构建或只读自检成功不代表已安装/升级/回滚、真实模型任务、音轨、睡眠唤醒、Intel Mac 或公开榜单通过。未运行项继续保留为 NOT_RUN/BLOCKED。
