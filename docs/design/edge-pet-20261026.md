## Anchor 与窗口

六个锚点：TOP_LEFT、TOP_RIGHT、LEFT_EDGE、RIGHT_EDGE、BOTTOM_LEFT、BOTTOM_RIGHT。窗口为 176×168 逻辑点乘用户大小，透明、无玻璃底板；只在聊天气泡使用原生玻璃。物理位置按当前显示器 work area 计算，避开菜单栏与 Dock，支持负显示器坐标和 Retina。

顶部图像向下揭示、侧边从对应边缘揭示，底部从下方缩回/抬起。身体在源姿态和 viewport 裁切中隐藏。换角时先完成 retract，经过 HIDDEN，再瞬间改变小窗口的位置，最后 peeking；没有穿屏路径或全屏 Overlay。小聊天入口始终可恢复角色。

## 状态与优先级

HIDDEN → RELOCATING → PEEKING → IDLE_EDGE；单击身体开始 RETRACTING → HIDDEN。显式交互只选择不同锚点，普通待机不自动打断输入。拖动按实际 AppKit 向量进入 DRAGGING，取消尚未完成的换角；松手短暂保留方向尾帧后返回最近边缘。位置恢复和气泡跟随不触发拖动状态。

CHAT_OPEN 阻止自动换角；WORKING、CELEBRATING、IDLE_POT 来自现有 Companion/Core 状态或真实闲置时间。Core 事件使用原有 task ID / SSE / Receipt / Verification，不能生成另一任务权威。WORKING 只在实际请求/任务执行时触发，动画按进入状态播放而非每个 token 播放。审批、拖动和交互优先；安静、动画关闭和系统 Reduce Motion 限制装饰动画。

窗口 Alpha 命中与 React 使用同一 source rect、uniform scale、clip、渲染坐标。聊天入口单独命中；原生点击身体换角，点击聊天入口打开已有气泡；原生拖动阈值 5 AppKit 点。左/右使用已存在、分别绘制的 atlas row 2 / row 1，上/下使用原有方向姿态。不镜像脸、饰物或文字。

## 诊断与恢复

`pet_edge` IPC 只提供状态、显式换角和聊天，不执行 Core 工具。现有私有控制 socket 支持 show/hide/inspect/quit；新增 center 仅供受控原生方向验收准备，不能把置中命令本身当作拖动证据。内存中最多记录 64 次本应用锚点放置和有限方向变化，没有跨应用鼠标轨迹或屏幕采集。

最终原生验收记录另放 `docs/acceptance/edge-pet-20261026/`，保留原生连续帧和所有失败。浏览器测试只验证 CSS/布局边界，不替代原生换角、方向显示或与 Codex 的共存测试。
