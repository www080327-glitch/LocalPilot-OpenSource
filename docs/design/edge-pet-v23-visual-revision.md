# 按图三修订的可评审实现

依据用户 19:25 / 19:26 的真实桌面失败截图与“哦鲸鲸……”表情图。前版视觉不再视为最终通过。

顶部：复用侧边左右姿态，手的实际接触线对齐屏幕外边缘，顶端贴可用区域顶部，保留菜单栏。侧边：同样对齐接触线，不能只对齐透明 PNG 的画布或最外侧手指像素。底部：无抓握动作，使用用户图三的呆萌、平涂、圆脸人像，身体自然裁在屏幕下缘。

思想气泡采用深蓝轮廓、白色椭圆与两枚圆点，默认“哦鲸鲸…”，中文字号 22；与人像形成图三式构图。点击气泡打开现有聊天窗口，用户输入与任务状态权威不变。点击身体触发换边，优先选择相反侧。

底部退出 1.15 秒：轻微上浮预备 → 带小角度的潜水弧线 → 头部沉到裁切边缘以下 → 尾巴最后出现、落下 → 完全隐藏。顶部退出使用侧身向上后退的弧线，不再像一张刚性卡片收口。新位置进入 1.35 秒，从对应外缘自然进入。没有跨桌面飞行，没有全屏透明层。

新增个人姿态包可选 extras：comic.png（图三风格透明无手人像），tail.png（独立、连着短尾柄的蓝色鲸尾），每张都有 SHA-256 与非透明内容 rect，和程序分离。原始用户图与原角色图集只读保留。

本文件描述源码设计，不是新二进制的渲染或验收证据。用户随后授权云端素材处理及必要低优先级单线程打包；素材已生成，新 App 的实测结果将在验收报告单独给出。
