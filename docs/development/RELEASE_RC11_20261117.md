## Verified scope

All four LocalPilot wheels were rebuilt from the published source. The build
verified 40 wheels and 286 packaged Python/Swift source files, followed by runtime
imports, `pip check` and Node checks. The extracted DEB ran through first setup,
actual Core b28/service-capability checks, the 24-hour draft selector, empty task
inventory and owned-process shutdown in real Linux WebKit. See the [RC11 package
report and manifests](../../desktop/docs/evidence/audit-20261117-desktop/final-package-rc11/RESULTS.md).

RC11 did not repeat animation measurement. Desktop frontend and native Rust
source are unchanged from RC10; the RC10 single-sample animation measurements
remain evidence for that earlier artifact, with conservative full-phase rates
of 28.5205 and 28.3160 visible changes per second. They are not relabeled as an
RC11 measurement.

The tested host is Linux x86_64 with glibc 2.41. Package dependencies include
Python 3.13, WebKitGTK 4.1, GTK 3, bubblewrap, zenity and the Ayatana app indicator.
Other Linux distributions/architectures and system-wide installation have not
been qualified. Apple Silicon and Intel macOS native builds and device tests
remain separate, unexecuted gates; this DEB is not a macOS artifact.

Long-running actual-model and public-evaluation results are maintained in the
audit and their own evidence directories. Their source identities are distinct
from the package and must not be described as tests of this installed binary.
