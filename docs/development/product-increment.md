# Product increment: implementation and evidence boundary

The existing Desktop is incrementally extended. Three columns, Graphite palette, sidebar, composer, task lifecycle and evidence inspector remain.

Core adds operator-authorized new-session options and local attachment import. Modes use the existing PermissionGateway; unsafe metadata, protected files, capability denials, macOS permissions, cloud egress and UNKNOWN receipts remain independent. Standard and minimal profiles share AgentSession, tools, persistence and verification.

Suite adds a versioned product coordinator, with authenticated oMLX admin capabilities, search, model information, downloads, jobs, cancellation/retry, settings and exact-name deletion of unloaded models. No arbitrary shell/URL interface is exposed. The pinned official oMLX 0.7.2 DMG is size/SHA256 checked; existing installations/settings are retained. A first installation can create local-only authenticated service settings without user terminal commands.

Files are selected by native picker/drop or pasted content. Core imports controlled copies with source, size, hash and authorization provenance. Images are previewed locally and remain ordinary files; no current vision claim or automatic cloud upload. Batch budget is 2 GiB with a 2 GiB free disk reserve.

Desktop now defaults to standard Agent. The minimal button creates an independent minimal Core session. One Aurora effort control and shared anchored popovers replace design comparisons. A separately toggleable original fish Companion window supports local chat and transfers the original question to the main composer for review. It does not automatically run the complete delegation chain.

Cache: this installed oMLX advertises prefix caching and has SSD caching configured. Per-model switches are stored preferences only, as the backend does not expose a qualified per-model enable/disable API. No prewarm or permanent retention claim. Restart restoration needs a real test.

Current qualification is PARTIAL. Clean macOS DMG-only installation is NOT_RUN. A separate candidate home is not a clean OS. Fresh model download/integrity/load, full real Agent/Companion acceptance and multi-display native pet behavior must be qualified separately.
