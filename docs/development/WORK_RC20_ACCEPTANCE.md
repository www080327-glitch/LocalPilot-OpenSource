## A. 本地 Work，执行模型选 6.1 Sol medium

执行模型与 LocalPilot 的受测模型是两回事。以下工作继续沿用原验收预算、夹具和通过条件。

### 1. Mac Test APP 和不丢数据的升级、回滚

在真实 M1 Max 按现有资源准备和 `desktop/scripts/build-macos.sh` 构建当前 RC20 Test APP。四组件 wheel 必须来自受测源码。使用 `src-tauri/tauri.test.conf.json` 和独立 `LP_INSTALL_TEST_ROOT`，先读现有安装脚本的 `--help`，再通过计划、执行和收据完成 RC18→RC20→RC18→RC20；不覆盖日常身份。

核验 Test Bundle ID、签名、架构、真实安装路径、四组件版本、包内容和实际模块加载来源。不得用源码目录覆盖安装 runtime 来测试。

RC20 活动检查点使用 schema 4；正常停止 Core 会自动整理成 schema 3，Suite 换包/回滚前也会准备兼容数据。用界面正常停止 Core 和 Companion，再执行已审阅计划。验证升级后新建任务、原文和收据在降级后的旧版可继续读写，再升级仍完整。UNKNOWN 不能因换版本自动重放。异常中断留下 schema 4 时，先用当前候选恢复并正常停服；不能让旧版读取过期完整快照，也不能恢复较早备份丢掉新记录。

### 2. 新手常用路线与错误恢复

运行仓库现有全部 Playwright 用例，保留逐项 reporter、失败截图和 trace；RC19/RC20 前端当前有 72 个收集用例。使用锁定依赖与现有 `LP_UI_CHROMIUM_EXECUTABLE` 入口，不关闭 sandbox。云端记录的“仅收集”“启动被阻止”不能记为页面通过。

在空白 Test 数据中，实际通过界面完成：选工作文件夹、连接模型、发出第一个文件任务、看结果、取消、重新查看任务。记录哪些步骤仍需要查文档、找隐藏路径或打开终端，修复具体死路。重点检查：

- 跳过下载会前进；没有模型时完成页明确提示并可返回。
- 只发现一个本地模型时自动选择；修改地址后旧模型与上下文预算清空。
- 更正密钥后实际后端使用新值，旧会话和其他模型保留；保存提供商后列表立即刷新。密钥不录屏、不写证据。
- 真实 `done` 目标显示已完成。新升级计划不会出现旧计划的成功或错误收据；停止服务过程中不提前显示已停止。
- 失败后保留草稿与原任务；结果未知时不会自动重复可能已经发生的操作。

不要用开发者自评代替“小学生都会用”。先验证无终端常用路线；实际用户观察必须有真实参与者，不能虚构。

### 3. 同一角色的动画细节

使用交付的 `LocalPilot-RC19-Personal-Pet-Atlases.zip`（同样适用于 RC20）。八套图集与上游原图字节一致；图像 CC BY-NC 4.0、JSON MIT，保留署名和许可，仅作个人非商业导入，不打进产品发行包。

在设置中点“选择角色文件夹”，选择与用户原角色相同、含 `pet.json` / `spritesheet.webp` 的目录，启用“使用基础动作”。验证实际可见、角色身份、缩放和重启保留，不自行换角色或重画。

真实鼠标向四个方向拖动，中途反向、按住停顿、继续和释放，观察收边、六个锚点和方向变化。验证大小滑块、标题栏 X 收起保留草稿、输入焦点与减少动态效果。跨屏需要真正第二个显示器，覆盖负坐标和不同缩放；单屏移动不算跨屏通过。

主动触发 `RETRACTING` / `PEEKING`，调用已有 `measure_animation` 并录制带时间的可见窗口。完整阶段内可见变化需达到 24 Hz；回调次数、CSS 报告或静态截图不能独立证明实际显示帧率。无阶段记 `NO_ANIMATION_STAGES`，不可见记未通过可见性，不写成有效 0 Hz。

高级探头、尾巴/水花及特定情节仍需要原私人姿态包：`pack.json`、`poses.png` 和清单列明的图片。只搜索用户授权的素材路径；找不到时列出缺失，不伪造、不上传私人画作。

### 4. 真实模型、音轨和休眠等设备功能

先核对原 R12 Luna medium Full 和 7,219.684 秒／240 心跳安装态长任务记录，它们属于原版本。对当前 b37 先做安装态检索、长任务保存、停止和恢复；若做真实工程复验，使用现有 `scripts/qualify_openai_engineering.py`，保留原提示、夹具、两个 child 和 4096 child 输出上限。

先使用已授权的 `gpt-6-luna / medium`；只有实际能力问题才用 Sol 对照，记录具体模型和 effort。密钥缺失、TLS、系统权限、测试启动错误与模型能力分开。不要增加预算或放宽外部验收来制造 PASS。所有子任务须有各自自测和外部验收，所有失败与重跑保留；自动审批拒绝要如实记录，不换入口绕过。

继续真实麦克风与系统音轨、中文会议转写和引用、系统权限、锁屏/睡眠/唤醒和问候。按真实 provider 指标测 oMLX 冷/热、卸载和重启缓存，不用上下文 token 数冒充缓存命中。

### 5. 独立 Intel 与 Debian 门禁

真实 Intel Mac：macOS 15+，原生 x86_64 Python、依赖和 APP，按照已有 Intel 指南用真实 CPU/HTTP 模型完成安装、任务、恢复与桌宠。M1、Rosetta、交叉编译不能替代。

Debian 13 x86_64：用本轮对应源码的 Test DEB 和散列，在具备正常系统依赖和桌面的机器完成首装、升级、降级、恢复；从普通用户图形会话启动。先正常停 Core，再用包管理器更换旧包。分别验收 X11/Wayland 拖动与位置能力，不把 Wayland 的不可用坐标写成零点。云端 RC19 因缺少系统 `WebKitNetworkProcess` 未出现窗口；包内测试和 ELF 提取不替代正常系统安装。无该设备就保留未执行。

## B. 云端 Work，执行模型选 6.2 Sol medium

独立审计同一 PR 的最新 head。把发现分为产品问题、模型输出、环境阻塞和报告错误，先给具体复现再做最小修复。保留已有失败，不因为此前使用 Luna 就否定报告，也不把测试全绿说成不存在 Bug。

优先复核已经实现的增量保存：实际生产持久边界没有在分块之前整体复制/序列化历史；父子任务收据没有经另一条路径重复全量写入；完整原文、原预算、批准、取消、UNKNOWN 和不重放语义保留。核对相同 96 次读文件夹具的原始指标，区分提交给 SQLite 的 JSON 载荷与物理磁盘 I/O，并分别报告任务结束、停服转换和恢复成本。必要时沿用原夹具复现，不另做更简单负载替代。

检查块事务故障、损坏/丢失、混合旧检查点、旧 journal 不变及退役会话缓存；使用未修改 RC18 做同一数据库的降级后继续写入再升级。Suite 转换必须发生在换包前，坏块或 owner 锁必须阻止换包。正常界面停服、原计划 fingerprint 和失败后重试应可工作。

继续使用现有单元、集成、页面和安装入口审阅实际缺陷，不新增另一套 Runtime 或复制业务逻辑的测试。源码缺口仍要单列：通用 Linux GUI 操作型 Computer Use 需要真实桌面实现与验收；通用 HTTP 持久 KV 取决于具体提供方能力；LoRA/全参个人训练需要审阅真实数据和独立测试集，RL 不自动加成用户必须完成的项目。硬件/数据不可用不能伪造效果。
