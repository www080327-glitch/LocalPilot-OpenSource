# localpilot AIC 独立候选

本轮基于 main `9a21ebbe`、PR #5 RC.6 `1971d97a`，在独立工作树合入 PR #4 `785618d6`。不修改 main、Latest、日常 APP、既有模型服务或备份。大肥鱼队；自有代码 MIT，比赛期间私有，赛后计划公开。本文件说明实际代码边界，不代替最终实验结果。

## 模型推荐与训练

`recommend_primary` 是 main / Suite 的产品入口。在硬件、内存、上下文、禁用类别及显式 allowlist 之后尝试已打包的 MLP。预测器只收到候选副本，输出再匹配原始准入对象；异常与非有限/非正预测回退。物理内存用于模型特征，实时可用内存另作硬上限。推荐是提案，不自动安装、加载或授予权限。

原网络训练目标是历史 `log(decode TPS)`，只适用于已记录 M1 Max / 64GB、模型和上下文范围内的速度目标。其他目标保留明确回退，不能声称所有质量偏好的正式替换已完成。Router 仍管理已经部署的本地/云端后端，与目录推荐器分开。

新增训练容量和 L2 控制。`benchmarks.aic_selector_training` 只在原训练 25 行内部按整组上下文调参，再报告原历史 8 行留出；不以旧规则或测试答案造标签。当前小网格仍选中原来的 8 单元、L2=0，未显示收益；新候选未晋升。旧数据条件不完整且已被历史报告公开，不能称作新独立质量评估。未来应补真实任务成功/失败与资源标签，按任务/模型/设备组冻结分割并校准。

接电后另完成两候选反事实：同一oMLX/Cache OFF环境、固定Qwen3.6-35B-A3B与Qwen3.8-27B权重，开发2例和评估3例各跑两候选，共10次模型任务，云端调用0。评估三例两候选均0/3；规则和MLP在生成前均选35B并共享该模型实测。因此“成功优先、成功者中墙钟最短”的观测oracle未定义，选择准确率为UNKNOWN，不能写成0%或100%。追加不增加独立样本数，标签未回灌权重；同一35B在vLLM主表和oMLX追加条件下的结果不能合并。完整反事实没有带来MLP质量替换的通过证据，仍为NO_GO。

## 公平实验

新 `benchmarks.aic_bfcl` 固定 BFCL V4 commit `6ea57973c7a6097fd7c5915698c54c17c5b1b6c8`，只暴露公开内存模拟器。开发/评估按预定哈希顺序分开，排除旧四例；答案在生成后才由原 checker 读取。七组为 A 原生 DSH 云端、B LP 完全云端、C 云端优先、D 平衡、E 本地优先、F 完全本地、G 原生 DSH 相同本地 Qwen。

总体请求、工具、输出和时间预算一致；瞬时请求错误最多重试一次，仍占实例总预算。原生系统指令和自身协调机制属于各自 Harness，工作工具环境相同。仅在禁用通用协调器且只有一个合规后端时移除无用模型切换描述，保留完整协调器的历史调用兼容性；没有删去关键权限或任务上下文。

评估前固定代理/驱动源码哈希。轮次转动并交替反转组别顺序，串行推理。原始请求、实际 Usage、错误和重试都留存；实际发票 UNKNOWN。共同峰值费率用于架构比较，时段折扣、免费额度和未测本地电费不能当作架构节省。n=4 不能证明统计非劣效。

旧四例仅为修复前诊断：A/B/C 为2/4，D/E/G为1/4，F为0/4。B原驱动曾把末轮error覆盖为generated，严格审计已按原始轮次修正，原始记录不变。另发现旧DSH云端模型目录仍宣告1M上下文，默认值未覆盖为预定64K，故旧队列不具备严格固定上下文的公平对照资格。新协议 `bfcl-protocol-qualified.json` 显式配置64K、修复通用工具提示，并保留原评分器。随后完成开发2例×7组及未见评估3例×7组，主表仅用新三例，不合并为n=7。

新三例严格成功为A 2/3、B/C/D 3/3、E 2/3、F/G 1/3。原生DSH云端第三例在工具尝试和API错误后耗尽32次统一provider预算，保留失败，不选择性重跑。C/D本队列没有实际本地推理。E的共同峰值标准API节省范围为19.4%～92.9%，来源为未知用量保守界，非统计区间或扣款发票；质量等效及稳定节费仍未证明。完全本地与原生本地成功数相同，前者P50更慢。实际API用量、错误、重试、逻辑主路由切换与物理provider转换分别保留。

Terminal-Bench 2.0 与 SWE-bench Verified 的预检缺少容器运行环境，未冒充已测。其他容器 CLI / VM 应用检查也未找到可直接复用的独立环境。

## 缓存与本地运行边界

DeepSeek 没有文档化 OFF 开关，云端只报告冷前缀与实际命中的重复前缀，含多轮、工具与新客户端；服务端重启和 device Prefill/内存为未知或未运行。命中不保证加速，先后两轮的加速和退步都保留。

补测使用64K容量配置和8341 Token长夹具，48/48响应及输出检查通过。长重复各OFF/ON两次的TTFT中位数比为oMLX 59.47、vLLM 6.41；实际每次命中8192和7392 Token。oMLX OFF波动26.80～106.69秒，固定先OFF后ON而非ABBA，不构成稳定加速资格。短标准提示两后端均没有实际KV命中；重启后的本短提示也无命中。云端同一冻结前缀在98.9分钟和随后332.3分钟的新进程探针中均命中9856/10099 Token，仍不能证明永久缓存。provider阶段Prefill、端到端、CPU/RSS和无收益项均另附，纯设备Prefill与内部KV数值资格保持未知或未运行。

`aic_local_study` / `aic_cache_local` 在北京时间 2026-10-29 09:30 前硬拒绝本地模型。用户随后明确选择接电后的正常性能模式；最终批次要求 AC Power 且省电关闭，并逐例留存电源状态。早期接电切换导致的开发中断单独保留；不与最终评估混为同一电源条件。只创建/停止本轮 vLLM/oMLX 进程，不接触日常服务；内存不足直接阻塞。固定 Qwen revision `38740b847e4cb78f352aba30aa41c76e08e6eb46`，无跨模型 KV 复用。oMLX / vLLM 完整内部 KV 数值资格和长期压力仍需另测。

## 复现准备

Mac 原生组使用固定 DSH 0.2.1-rc.2、已有固定权重和已验证独立服务环境；不自动下载模型或安装 APP。BFCL 源码放在 `.aic-runtime/references/gorilla`，checkout 上述 commit。固定协议记录数据、checker、驱动和 DSH 安装资产哈希；漂移拒绝执行。真实云端凭据仅由宿主的显式项目凭据文件提供，不进入模型消息、子进程或源码包。

先运行 `python -m benchmarks.public_preflight`。独立部署环境满足前提后运行 `python -m benchmarks.aic_bfcl --freeze --manifest NEW.json`；开发集通过环境检查并锁定实现后，运行 `python -m benchmarks.aic_local_study --split evaluation --manifest FROZEN.json --run NEW_RUN`。这些是 adapted 研究驱动，硬编码的本机默认服务环境需按复现机器明确配置；不能当作跨平台即用发行版。
