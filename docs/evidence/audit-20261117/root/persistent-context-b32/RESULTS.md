## 升级与持续使用边界

Core runtime 从 SQLite **schema 1 升为 2**，迁移前自动用 SQLite backup API 创建同目录、独立命名、0600 权限的备份，并核对完整性和版本。旧 RC14 会拒绝 schema 2，避免在看不到归档幂等键时重复执行。回退旧代码需要先停服务、恢复升级前的数据备份；升级后新记录不在该备份里，不能只把版本号改回 1。

本轮解决活动模型窗口和累计执行名额的问题，**单个一直打开的 Core 会话仍会保存并序列化完整原始记录**；没有完成无限增长记录的分段存储。Companion 默认保留 10,000 条聊天，已遗忘、失效或超过保留政策的内容不会恢复。64 个仍打开的会话仍占用名额；系统不会擅自关闭用户工作。

未把缓存 TTL 固定成“Claude 一律一小时”，也未设置闲置 55 分钟自动触发付费压缩。不同提供方与缓存设置要按实际接口验证；本轮稳定前缀与提供方诊断只提供可观察的请求证据。
