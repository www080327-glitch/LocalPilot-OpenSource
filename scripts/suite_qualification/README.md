# Qualification tools

`contract_matrix.py CORE_SOURCE COMPANION_PARENT` runs an actual consumer/provider source pair using real HTTP/SQLite and an explicitly scripted model. `run_regressions.py ROOT OUTPUT [TEST_DIRECTORY]` blocks model libraries during regression. Set `LOCALPILOT_SOURCE` and `PYTHONPATH` to the selected Core and Companion source when required.

Other tools in this directory retain the initial battery-phase installation/cloud/fault controls; their version paths and environment layout are historical fixtures, not final RC2 model evidence. Use the RC2 release report and sanitized evidence hashes for the actual final installed-package runs. Raw native/model acceptance drivers and provider payloads remain local because they reference the operator's protected environment. No test script grants ordinary tokens approval authority.
