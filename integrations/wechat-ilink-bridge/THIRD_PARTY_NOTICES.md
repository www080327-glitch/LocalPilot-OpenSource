# Protocol reference

The iLink request shapes and QR login flow were adapted from
[NattoCB/dsh-plugin-wechat-bridge](https://github.com/NattoCB/dsh-plugin-wechat-bridge/tree/88257abad5bd3c676c1c2528fb8e2d1d97a5f50e),
particularly `src/weixin-api.js` and `src/weixin-types.js`. No DSH runtime code
or vendored dependencies are required here. The upstream files also credit
CodePilot's WeChat protocol implementation.
